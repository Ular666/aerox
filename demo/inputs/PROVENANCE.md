# Demo input provenance

GUARD uses three real aerial stills from the team's development-validation subset of VisDrone2019-DET. Each still is held for two seconds to exercise the MP4 pipeline. This clip does not show a flight sequence or establish field performance. Source image names: 0000016_00420_d_0000068.jpg, 0000071_07349_d_0000012.jpg, 0000106_00673_d_0000050.jpg. Dataset credit: AISKYEYE, Tianjin University. [Upstream dataset](https://github.com/VisDrone/VisDrone-Dataset). Confirm permission for public use before posting samples or derivative clips.

AGRI uses a programmatically generated RGB field pattern with exactly 53.125% green pixels by construction. It exercises the code path and cannot estimate field accuracy.
