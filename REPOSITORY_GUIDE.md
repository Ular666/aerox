# AEROX repository guide

- Root: qualification application copied from the prepared AEROX_2_0 build.
- models/: included model weights.
- demo/ and evidence/: demo inputs, outputs, and technical evidence.
- pitch/ and sanzhar/: video guidance and handoff materials.
- legacy_mvp/: original MVP top-level source and base models; original environment and datasets are not copied.
- archive/desktop_snapshot/: desktop Aerox materials, including videos, documents, and previous versions, preserved without overwriting originals.

Run start.ps1 from the repository root. See README.md for dependencies.

Publish this repository as PRIVATE for team review. Source-media permissions and redistribution terms must be checked before public release.

The archive contains earlier versions. Their claims and metrics are not automatically authoritative for the root application.
